# Branding

Cover logos used by `common/tools/make_docx.py`:

| File | Logo |
|------|------|
| `bsi_logo.png` | buildingSMART International |
| `bsusa_logo.png` | buildingSMART USA |

Both are placed side by side at the top of the cover of each part, as on published buildingSMART International documents, and drawn at the same height (`LOGO_HEIGHT_IN` in `make_docx.py`). The files are trimmed to the logo artwork with no surrounding padding, so equal heights give equally sized wordmarks. A missing file is skipped.

Use only logo artwork supplied by, or approved for this use by, buildingSMART International and buildingSMART USA.
